# Rickroll Minesweeper

Minesweeper with a catch. **[Play it here.](https://ikeasourpatches.github.io/rickroll-minesweeper/)**

A 10×10 board with 15 mines, all in one HTML file with no dependencies. Left-click to reveal, right-click to flag.

Reset works fine the first time. Press it again and you'll meet a certain Rick Astley video.

To run it locally, open `index.html` in a browser.
